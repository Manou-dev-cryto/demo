# AstroQuiz

Un quiz interactif en français pour tester ses connaissances de l’espace. Réponds à 10 questions, découvre ton score et relance la mission autant de fois que tu veux.

## Jouer en local

Ouvre `index.html` dans un navigateur. Aucune installation ni dépendance n’est nécessaire.

## Déploiement sur GitHub Pages

Le workflow GitHub Actions dans `.github/workflows/deploy.yml` publie automatiquement le site sur GitHub Pages à chaque mise à jour de la branche `main`.

Dans le dépôt GitHub, vérifie que **Settings > Pages > Build and deployment > Source** est réglé sur **GitHub Actions**. Après le premier push, le déploiement est visible dans l’onglet **Actions**.
